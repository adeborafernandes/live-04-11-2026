## Como usar o notebook

1. Abra o `.ipynb` no [Google Colab](https://colab.research.google.com) (*Arquivo → Fazer upload de notebook*).
2. Salve uma cópia no seu Drive.
3. Rode as células **na ordem**. A pasta `/content` some quando o Colab desconecta; se isso acontecer, rode tudo de novo.

O notebook usa o dataset *Telco Customer Churn* (IBM), baixado direto do GitHub.

Os slides não estão neste repositório.
